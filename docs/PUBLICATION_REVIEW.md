확인일: 2026-10-19 (한국 시간). 이 문서는 최초 로컬 공개 준비와 후속 사용자 확인을 기록합니다. 아래의 커밋·원격 상태와 미수행 작업은 최초 점검 당시를 기준으로 합니다. 이후 사용자가 `Jordi2801K/Sprout_English` 저장소 게시를 요청했습니다.

기존 파일 5개는 수정 전에 각각 부모 디렉터리의 `backups/v1.x/`에 복사하고 SHA-256 일치를 확인했습니다. README와 이 기록의 추가 수정 전에도 별도 버전으로 백업했습니다. 각 백업 폴더의 `SHA256SUMS`에 해시를 기록했습니다. 기존 백업은 덮어쓰지 않았으며 모든 `backups/`는 공개 대상에서 제외됩니다.

## Git과 민감정보 점검

- 최초 점검 당시 브랜치 이름은 `main`이며 커밋·추적 파일·브랜치 참조·태그·리플로그·등록된 원격이 없었습니다. 파일별 기여와 과거 작업 내역은 Git 이력으로 확인할 수 없습니다.
- 커밋은 없지만 `.git`에 도달 불가능한 파일 객체 등이 남아 있습니다. `.gitignore`는 해당 객체를 지우지 않습니다. `.git`을 포함한 작업 폴더 자체를 외부에 공유하지 않습니다.
- 현재 `.env`에는 API 키와 DB 접속 정보가 있습니다. 값은 출력·수정하지 않고 공개 대상에서 제외했습니다. 현재 점검으로 외부 유출 여부나 키의 유효성은 확인하지 않았습니다.
- Git 객체의 초기 토큰 의심 2건은 HTML의 `task-…` 식별자에 대한 오탐이었습니다. 토큰 앞 문자 경계를 확인한 결과 검사한 객체에서 실제 API 키를 발견하지 못했습니다.
- 녹음 파일, SQL 스냅샷, 파일 기반 벡터 데이터, 대화 내보내기, 개인 요약 문서와 PDF, 가상환경·빌드·삭제 후보 사본을 로컬에 보존하고 공개 대상에서 제외했습니다.
- DB 테이블 정의 SQL 3개는 유지했습니다. 데이터 삽입문이 있는 `snapshot*.sql` 2개와는 구분합니다.
- 공개 후보 텍스트의 API 토큰·개인키·개인 절대경로 패턴을 재점검했습니다. 해당 패턴은 발견되지 않았습니다. 패턴 검사는 모든 비밀·개인정보가 없다는 보증은 아닙니다.

검사 과정에서 비밀 값은 출력하지 않았습니다. 상세 경로·객체 검사 범위는 공개 제외된 `docs/local_only/publication-audit.md`에 기록했습니다.

## 실제 검증 결과

기존 서버 가상환경(Python 3.10.18)과 기존 Flutter 의존성 환경을 사용했습니다. 새 패키지 설치·모델 다운로드는 수행하지 않았습니다.

| 검증 | 결과 | 범위 |
| --- | --- | --- |
| 서버 `unittest discover` | **20개 통과** | 기존 17개 + 설정·빈 저장 폴더 회귀 테스트 3개 |
| Flutter `flutter test --no-pub` | **36개 통과** | 화면 이동, 설정·프로필, 통계, Writing 결과 처리 등 기존 테스트 |
| Python 구문 검사 | **50개 파일 통과** | 가상환경·백업을 제외한 `server/`의 `.py`를 AST로 파싱 |
| 실행 보조 스크립트 구문 검사 | 통과 | 로컬 STT 스크립트 `zsh -n`, Android 연결 스크립트 `bash -n` |
| Flutter CLI 정적 분석 | 실행 불가 | SDK의 `engine.stamp` 갱신이 샌드박스 쓰기 제한으로 차단됨 |
| 캐시된 Dart SDK 직접 정적 분석 | 종료 코드 0, 진단 출력 없음 | `dart analyze --format machine`; Flutter CLI 분석 성공으로 간주하지 않음 |
| `.gitignore` 점검 | 통과 | 백업·실제 `.env`·녹음·스냅샷·벡터·모델 경로 제외, 예시·소스·테스트·lock 파일 유지 |
| HTTP 라우팅 스모크 검사 | 3개 경로 HTTP 200 | 임시 폴더·ASGI에서 `/healthz`, `/openapi.json`, `/roleplay/catalog` 확인. startup/lifespan·DB·외부 API 미실행 |
| 공개 후보 내용 검사 | 316개 파일 점검, 해당 항목 미탐지 | API 토큰·개인키·개인 절대경로, 실제 `.env`의 API 키·DB 비밀번호 일치, DB·녹음·로그·모델 산출물 검사. 이미지 49개는 텍스트 패턴 검사 제외 |
| Markdown 링크·환경 예시·백업 해시 | 통과 | 상대 파일 링크 존재, 활성 예시 7개 값 공란, 백업 7개 해시 검증 |

서버 테스트는 다음 명령으로 실행했습니다.

```bash
cd server
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -B -m unittest discover \
  -s tests -p 'test_*.py' -v
```

이번에 실행하지 않은 범위:

- 실제 OpenAI API 호출과 응답 품질, 비용·계정별 모델 사용 가능 여부
- MySQL 연결, 테이블 생성, 데이터 저장·조회, Alembic 마이그레이션
- Qwen 모델 로딩·워밍업·음성 인식·성능 측정
- 실제 마이크 녹음·TTS 재생, Android/iOS 등 실기기 시연과 플랫폼 빌드
- 빈 PC·새 가상환경에서의 전체 의존성 설치와 실행
- 외부 의존성 취약점 검사, 전체 보안 감사, 바이너리·압축 파일의 내부 개인정보 검사

## 남은 작업

1. 제공된 영상 링크의 외부 재생과 공개 설정을 확인합니다. 영상의 포함 장면과 민감정보 노출 여부는 아직 확인하지 않았습니다.
2. 팀원별 세부 기여 범위와 수상 증빙을 보완합니다.
3. 새 환경 설치와 API·DB·Qwen·실기기 통합 검증을 수행합니다. 의존성 선언(`requirements.txt`, `pyproject.toml`, `uv.lock`)의 차이와 레거시 마이그레이션을 정리합니다.
4. 공개 직전 후보 파일 전체를 다시 검사합니다. 이전에 실제 키를 외부에 공유한 이력이 있다면 폐기·재발급을 진행합니다.

최초 로컬 공개 준비에서는 원격 저장소 생성·push·공개 전환·커밋·스테이징·Git 이력/객체 정리·재작성을 수행하지 않았습니다. 문서·기능 준비 상태는 **로컬 문서·설정 정리 및 팀 공개 동의 완료, 권리 검토 생략, 시연 링크 연결 완료, 통합 검증 대기**입니다.
